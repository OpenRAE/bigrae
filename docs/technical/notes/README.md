# Internal notes and retained evidence

These notes contain earlier infrastructure descriptions, integration plans, prompts, links, and screenshots.
They are reference material for their original context.
They do not establish a supported deployment or authorize execution of retained commands.

The [earlier architecture summary](architecture-summary.md) describes an older AWS layout.
The [current architecture handbook](../architecture.md) describes the current Helm control plane and provider boundaries.
The [retained plans](../plans/README.md) explain how to interpret related implementation proposals.

The notes do not consistently identify an exact source revision or deployed environment.
A file's last commit identifies retained bytes; it does not identify the deployment that those bytes describe.
Where the original baseline is missing, the evidence cannot be reproduced from the note alone.

Screenshots and prompt files remain source-bound records.
Their inclusion here does not authorize publication of private content or use as current agent instructions.
The MkDocs exclusion is a publication setting, not a privacy control.
