# Manual deployment

Use [Install on Google Cloud](../../getting-started/install-gcp.md) for the current manual procedure.
It uses the published release container and does not require a repository clone.

The procedure includes:

1. Project access, billing, and tool checks.
2. Google and GitHub sign-in.
3. Release verification.
4. Complete deployment input files.
5. Initial installation.
6. DNS and certificate setup.
7. Readiness and range smoke checks.
8. Initial administrator sign-in.
9. Updates, recovery, and removal.

Use [Deploy with a coding agent](../../getting-started/deploy-with-agent.md)
to delegate the same procedure.
The [GCP deployment reference](../handbook/gcp-github-less-deployment.md)
describes the individual commands.

AWS support is coming. The older AWS development deployment is not the user installation path.
