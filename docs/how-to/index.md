# How-to guides

Use these guides when you know the task you need to complete.
For a learning exercise, use [Launch your first range](../getting-started/quickstart.md).

## Getting started

Use [feature guides](../features/index.md) for range, terminal, account, and event tasks.
Use the [scenario catalog](../scenarios/index.md) to select installed content or upload an approved pack.

## Advanced setups

- [Admit pack experiments](admit-pack-experiments.md): retain approved scientific inputs without dispatch.
- [Run experiment batches](run-experiment-batches.md): run admitted trials on disposable workers.
- [Manage the RAES image registry](manage-raes-image-registry.md): register, list, or disable provider image mappings.
- [Retain trial archives](retain-trial-archives.md): collect and retrieve original evidence in approved custody.

These tasks require the stated administrator authority and an operator-prepared environment.
Their management commands do not create a supported installation path from a normal user's computer.
