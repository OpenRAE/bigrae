# Deprecated documentation reference

These files preserve earlier documentation and proposals.
Their original statements describe an earlier context, even when they use words such as “current” or “today.”
They are not supported operating instructions.

- [Version 1 documentation](v1/index.md) retains the first documentation tree.
- [Version 2 documentation](v2/index.md) retains the later documentation tree and its proposed features.
- [Current architecture](../technical/architecture.md) describes present ownership and support limits.
- [Current installation guidance](../getting-started/install-gcp.md) provides the supported GCP entry point.

The directory name identifies deprecated documentation, not a product release qualification.
The files do not consistently record the source revision or deployment that they describe.
A retained commit therefore proves the document's bytes, not the historical deployment's behavior.
Dates, commands, identifiers, quotations, and original evidence remain unchanged.

This directory stays outside the published MkDocs site.
That exclusion does not protect private data or authorize republication of old private details.
