# Show realized native range instances

The scoped range read already authorizes the public range and verifies matching CMS and Engine custody. Its instance projection currently reads only the retired range specification, which is absent for native packs.

For a range without that specification, query Engine's existing ready-instance facade with the recorded owner, request UUID, public range UUID and workspace. Pass the result through the existing template-safe instance projector. Add the existing `raes-node` role to that display schema. Keep the allowlist of fields and existing remote-access decisions. No provider payloads, key references or passwords enter the response. Ranges with a stored specification keep their existing projection.

Validate realized instance display, secret-field omission, native readiness and existing custody checks with synthetic data. The frontend already uses the public instance fields to show terminal and remote desktop actions. No frontend or deployment image build is needed.
