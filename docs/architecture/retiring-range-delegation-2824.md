# Keep retiring ranges out of delegation checks

Administrator grants check the actions that a new role can obtain on live resources. A range in the destroying or destroyed state has already left normal user control. Its authorization relationships can be removed while Engine keeps its runtime row and sealed cleanup proof.

Exclude these two terminal lifecycle states from workspace and event delegation inventories before applying their bounds or projecting range authority. Keep all ancestry checks for live ranges. Do not change direct binding reads, retained cleanup records, cloud custody, or provider checks. This prevents an old, unavailable range from blocking a new administrator grant without adding authority to that range.

Tests verify both inventory paths, malformed live ranges, and direct binding reads of retained rows.
